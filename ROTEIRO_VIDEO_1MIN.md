## 🎥 INSTRUÇÕES DE GRAVAÇÃO

### Equipamento Necessário
- **Captura de tela:** OBS Studio ou Loom
- **Microfone:** Qualquer microfone USB ou headset
- **Edição:** CapCut, DaVinci Resolve (free) ou iMovie

### Preparação da Gravação

1. **Limpar ambiente de teste:**
   ```bash
   # Backend
   cd backend
   uvicorn main:app --reload --port 8000

   # Frontend
   cd frontend
   npm run dev
   ```

2. **Abrir telas para gravar:**
   - Navegador: `http://localhost:3000` (App)
   - Navegador: `http://localhost:8000/docs` (Swagger)
   - WhatsApp Web (para demonstração)
   - VS Code (código, opcional)

3. **Preparar conta de teste:**
   - Criar usuário "Demo User"
   - Adicionar transações de exemplo
   - Ter algumas missões ativas

### Sequência de Capturas

**Segmento 1 (0:00-0:10):**
- Slides estáticos com estatísticas
- Animação de texto

**Segmento 2 (0:10-0:20):**
- Tela inicial do FINAP
- Mascote FIM (screenshot)
- Logo

**Segmento 3 (0:20-0:35):**
- Navegar pelo dashboard (3s)
- Abrir chat FIM, enviar mensagem (5s)
- Ver tela de badges e XP (3s)
- Transições rápidas

**Segmento 4 (0:35-0:45):**
- WhatsApp Web aberto
- Enviar mensagem ao bot
- Mostrar resposta
- Voltar ao app (transação aparece)

**Segmento 5 (0:45-0:55):**
- Split screen:
  - Esquerda: Swagger UI (scroll rápido)
  - Direita: App funcionando
- Diagrama de arquitetura (2s)

**Segmento 6 (0:55-1:00):**
- Fade out para tela final
- Logo + informações

### Dicas de Gravação

1. **Pratique antes:** Grave 2-3 vezes para pegar o timing
2. **Fale com energia:** Tom entusiasmado, mas não gritando
3. **Velocidade:** Fale claramente, mas mantenha ritmo
4. **Pausas:** Pause 0.5s entre frases principais
5. **Transições:** Use fade rápido (0.3s) entre segmentos

### Edição

**Efeitos Recomendados:**
- Zoom suave em elementos importantes
- Setas/círculos para destacar features
- Texto animado (entrada lateral ou fade)
- Música de fundo (instrumental, volume 20%)
- Transições: crossfade ou slide

**Música de Fundo Sugerida (royalty-free):**
- Epidemic Sound: "Tech Upbeat"
- YouTube Audio Library: "Energetic Tech"
- Artlist: "Corporate Motivational"

**Paleta de Cores para Texto:**
- Primária: #6B46C1 (roxo FINAP)
- Secundária: #00D4AA (verde água)
- Destaque: #FFFFFF (branco)
